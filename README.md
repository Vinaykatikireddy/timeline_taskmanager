# Timeline Task Manager

A modern timeline-based daily task manager and adjuster built with pure HTML, CSS, and JavaScript.

Check Site here:  
[Timeline Task Manager](https://vinaykatikireddy.github.io/timeline_taskmanager/?utm_source=chatgpt.com)

---

## Features

- Timeline-based scheduling UI
- Drag-based tasks adjustment
- Non-overlapping task layout
- Desktop Centered design
- LocalStorage persistence
- Date-based task separation
- No cloud storage required
- Zoomable timeline
- Task editing and deletion
- Color-coded tasks

---

## Desktop Centered Layout
- Interactive timeline
- Side task panel
- Timeline zooming
- Overlap-aware rendering

---

## Tech Stack

- HTML5
- CSS3
- JavaScript

No frameworks used.
